# MeuTreino v1.0

App estático para acompanhar treinos. Dados de cargas, conclusão, tênis e histórico ficam no armazenamento local do navegador.

## Publicar no GitHub Pages
1. Envie os 5 arquivos para a raiz do repositório.
2. GitHub > Settings > Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Branch: main. Folder: / (root). Salve.
5. Aguarde a publicação.
